# 🎯 Guess the Word

A simple and interactive web-based word guessing game built with **Python and Flask**.

## 📌 Overview

The application randomly selects a word and hides some of its letters. Players must guess the complete word using the visible letters as clues.

Players have **3 attempts** to guess the correct word.

---

## ✨ Features

- 🎲 Random word selection
- 🔤 Partially hidden letters as clues
- 🎯 Word guessing gameplay
- 🔢 Limited attempts
- ⚡ Instant feedback for correct and incorrect guesses
- 🌐 Simple web-based interface

---

## 🛠️ Tech Stack

- **JavaScript**

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/SaiSreekari-Kudaka/guessword.git
cd guessword
```

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python guesstheword.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

---

## 🎮 How to Play

1. Look at the partially revealed word.
2. Use the visible letters as clues.
3. Enter your guess.
4. Guess the correct word within **3 attempts**.
